# SWARG — Himalayan Cloud Retreat
### Luxury Client Demonstration Package

This is a premium, static single-page web experience crafted for demonstrating **Swarg** to international luxury clients and resort developers.

---

## 🎨 Three-Tone Design System
1. **Deep Tone — Slate Mountain Blue (`#0F172A` / `#1E293B`)**: Grounding foundation reflecting Himalayan bedrock and alpine dusk.
2. **Mid Tone — Mist Silver (`#94A3B8` / `#CBD5E1`)**: Frosted platinum borders, glassmorphic panels, and subtle glows.
3. **Light Tone — Snow White (`#FFFFFF` / `#F8FAFC`)**: Pure snow accents, editorial serif headings, and crisp readability.

---

## ✨ Interactive Demo Features for Foreign Clients
- **Live Multi-Currency Switcher**:
  - Located directly in the top header.
  - Toggles between **USD ($)**, **EUR (€)**, **MVR (Rf)**, and **INR (₹)** with real-time instant price recalculation across all suites and booking estimates.
- **Dynamic Himalayan Weather & Elevation Ticker**:
  - Elevation: `8,250 FT / 2,514 M`
  - Current condition: `-2°C Crisp / Clear Skies`
  - Real-time Nepal/Himalayan Standard Time clock (`UTC + 5:45`).
- **Suite Details Drawer / Modal**:
  - Click **"Details"** on any suite card to open a full architectural specification modal with floor plan dimensions, butler services, and private thermal pool specs.
- **Interactive Reservation Bar & Modal**:
  - Floating check-in/out and suite picker on the Hero section.
  - Full VIP inquiry modal with real-time calculation of total stay price based on nights and selected currency.
  - Generates a realistic **VIP Reservation Reference Toast** (`SWG-XXXXXX`) with direct concierge dispatch status.
- **Editorial Typography**:
  - **Cormorant Garamond**: High-fashion, luxury editorial serifs.
  - **Plus Jakarta Sans**: Ultra-clean, contemporary international typography.

## 🚀 How to Run / Demo
You can open `index.html` directly in any web browser:
```bash
# Direct open:
xdg-open index.html   # On Linux
open index.html       # On macOS
# Or serve with any lightweight static server:
python3 -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.
